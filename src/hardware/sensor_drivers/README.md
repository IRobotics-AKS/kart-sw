# sensor_drivers

Integrate one OAK-D S2, two OAK-1 Lite cameras, BNO055, and the identified GNSS kit through pinned external vendor dependencies. Device IDs, transports, rates, calibration, and GNSS corrections are unresolved. No drivers or BRIO support are included.

This is an installable ament_python package with no executable. See the root
`docs/ros-structure.md` for target topics, ownership, timing, and frame contracts.
Add runtime dependencies and console entry points with the implementation.
