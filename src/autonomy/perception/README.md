# perception

Integrate explicitly selected camera/perception pipelines. Bind front, side_left, and side_right to stable device IDs. Vendor and Isaac ROS dependencies remain unselected; Coral is not required. No inference pipeline is implemented.

This is an installable ament_python package with no executable. See the root
`docs/ros-structure.md` for target topics, ownership, timing, and frame contracts.
Add runtime dependencies and console entry points with the implementation.
