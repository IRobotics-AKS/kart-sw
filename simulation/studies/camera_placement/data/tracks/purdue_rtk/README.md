# Purdue kart track

- `track_world.xml`: track world built from the 2021 RTK edge survey of the Purdue go-kart track (left and right edges). Built with aks-gps `scripts/build_purdue_track.py`. Lap 429 m, counter-clockwise, origin at the centre of the start line.
- `mintime_line.npz`: min-time racing line on that track (aks-gps `scripts/formula/build_line.py`), key `pts`.
